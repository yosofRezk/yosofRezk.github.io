## ⚡ Overview

Welcome to the personal developer portfolio of **Youssof Rezk**, a WordPress Developer based in Mansoura, Egypt. This portfolio serves as an interactive showcase of my work, specializing in custom WordPress theme development, bespoke plugins, WooCommerce engine customizations, and web performance optimization.

This repository features a clean, production-grade frontend architecture separating styling, dynamic data, UI components, and animation drivers into modular assets.

> **Design Attribution**: The layout, aesthetics, and overall design language of this portfolio were heavily inspired by the phenomenal work of [Simone Giussani](https://simonegiussani.it/).

---

## 🚀 Key Features & Highlights

- **Dynamic Interactive Environment**: Custom canvas/CSS aurora lighting beams with interactive 3D perspective mode toggle.
- **Scroll-Driven Scaling & Fade Engine**: Project cards dynamically scale, glow, and smoothly illuminate/fade out relative to screen viewport center (`Math.sin` & GSAP `ScrollTrigger`).
- **Interactive Case Study Modal**: Deep-dive project dialogs complete with role breakdowns, features list, technical architecture notes, technology chips, and live URLs—all smoothly rendering over the main layout.
- **Mac-Style Floating Dock**: A custom iOS/macOS-inspired floating dock and popup menu for seamless navigation.
- **Serverless Contact Form**: Fully integrated with **Web3Forms** using AJAX/Fetch for a seamless, page-reload-free user experience.
- **Lenis Inertial Smooth Scrolling**: Ultra-smooth inertia scrolling powered by Lenis and synchronized with GSAP animation tickers.
- **Fully Responsive**: Carefully adapted for mobile, tablet, and desktop devices to maintain aesthetic integrity across all screens.

- **Core Frontend**: HTML5, CSS3 Custom Properties, Modern Vanilla JavaScript (ES6+ Modular Architecture).
